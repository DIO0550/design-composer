# PR #526 ✨ ⌘G / ⌘⇧G で選択を Box で包む・解除する

- マージ日: 2026-09-13
- 関連 Issue: #416
- 差分規模: 31 ファイル / +1353 -100

## ゴールと結果

選んでいるノードを ⌘G で新しい Box の中へ入れられ、⌘⇧G でその Box を外して子を親へ戻せるようにする。コンテキストメニューの `Group` / `Ungroup` からも同じ操作ができる。達成した。

Issue は「複数選択が無いので #373 の A1（範囲選択）の判断が先」と書かれた状態で割り当てられたが、**両方とも既に決着していた**。範囲選択（#411）は入っており、そのうえで `docs/06-ui.md`「複数選択」が「編集操作は複数選択中は行えない（複数対応は #464）」と規定しているので、グループ化は単一選択の操作になる。docs と UI 案は割り当て（`⌘G` / `Shift+⌘G`）・メニューの行の位置・並ぶ条件まで先に書いてあり、この回で新しく決めたのは却下案として残した 5 点だけだった。

座標と大きさの引き継ぎはスコープ外にし、#527 へ分離した。
