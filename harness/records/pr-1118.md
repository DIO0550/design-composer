## ゴールと結果

ゴールは「描いてある四角の上で中ボタンを押して引くと、帯の上と同じく表示が動く。space を押しているときは今までどおり四角ではリサイズが優先される」。達成した。四角が主ボタン以外の押下を親へ渡し、親が土台と同じパンの入口へ差し込む形にした。パンの捕捉先は、押した要素から土台に変えた。

Issue の「決めること」が未決のまま起動したので、フェーズ 1 で選択肢を Issue に書いて止まった。オーナーの回答（推奨案でよい）で再開した。space + 右ボタンでパンするかは計画の未決として残り、承認された「判定を 1 本に保つ」の帰結として採った。docs にもいったん書いたが、実装の検証で右クリックのメニューと規則がぶつかると分かり、docs からは外して #1117 に切り出した。

GitHub 上の人のレビューは 0 件だった（`get_review_comments` / `get_reviews` は空、`get_comments` は自分のテスト表 1 件と `github-actions[bot]` の 3 件）。CI は head（7cd8a0c）で 9 件すべて成功し、VRT は差分 0 だった。表示確認は Chromium（Storybook `ArtboardCanvas` / `Selected`）で行った。WebKit は未検証。
