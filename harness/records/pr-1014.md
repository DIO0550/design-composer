## ゴールと結果

ゴールは達成した。リサイズで掴んだ回は、どこで離しても直後の `click` 1 回だけを飲み込み、次のクリックは選択に使われる。受け口を `ArtboardFrame` の `onClick` から、キャンバスの面(`section`)の `onClickCapture` へ移した。

- ゴールは計画の検証で「枠の外まで引いて離しても」から「ハンドルから掴んだ回は離した場所によらず」へ広げた(指摘 1)
- 人のレビュー指摘は 0 件(`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。コメントは自分のテスト表と bot の投稿だけ)
- CI は 1 回目ですべて通過(VRT 差分 0 / 189 件)
- 右ボタンでハンドルを掴む経路は、受け口を移しても直らないため #1012 に分けた
