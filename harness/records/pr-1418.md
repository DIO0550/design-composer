# PR #1418 tokens の hex の欄を UI 案の箱(#・6 桁・右端の %)にし、見出しを左に置く

- マージ日: 2026-11-22
- 関連 Issue: #1376
- 差分規模: 20 ファイル / +1674 -640

## ゴールと結果

ゴールは次のとおり。Tokens 画面の Color のエディタと gradients の stop の行で、hex を UI 案と同じ「`#` の前置き + 6 桁 + 右端の不透明度 `%`」の箱で見て・打てるようになり、エディタの欄の見出しが UI 案どおり左に並ぶ。

達成した。96px の色見本は計画の段階で今の実装に無いと分かったので、#1416 に分けた。

- **起動の扱い:** Issue の assign で自動起動した。最初に読んだ時点で `flow:*` ラベルが無く、本文の論点 1〜5 も人の判断を要したので、提案を Issue に書いて止めた。その後、人から「ラベルは付けた」「基本推奨でいい」と返答があり、`flow:feature` を確かめて再開した。
- **計画:** 計画は 3 版まで直した。plan-reviewer は第 1 版・第 2 版に回し、各 9 件の指摘をすべて採用した。第 3 版は回していない。
- **実装の検証:** 9 観点と test-reviewer を通した。PR を出した後に bot(Devin)の 2 件と人のレビューの 3 件があり、人のレビューで欄の書き戻しの形を 2 回作り直した。
  - 1 回目: `changeRawOf` の export を外した。
  - 2 回目: 方針 B。欄は `TokenRawEdit` を上へ渡し、読むのは 1 か所にした。
- **人のレビューの確認:** GitHub 上の人のレビューは、`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確かめた。DIO0550 の名で付いているコメントのうち、指摘は value-field:251 のスレッドの 3 件(「なぜ export」「ドメインに寄せる案は」「B で」)だけ。残りはこのセッションが貼った返信とテスト表。
- **CI:** VRT は TokenEditor の選択中のストーリー 6 件(Changed)と新規 2 件で、どれも意図した差分。`visual-approved` を待ってマージされた。ほかの CI はすべて緑。
