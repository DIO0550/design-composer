## ゴールと結果

ゴールは、Windows / Linux で動かしたときに、開始画面の「開く」「新規作成」カードの割り当ての綴りを、コンテキストメニュー（#480）と同じく動いている OS の綴りで出し、アプリ内で綴りを揃えること。達成した。

- 綴りの規則を `editor-context-menu` の非公開の場所から `src/components/shown-shortcut`（`ShownShortcut.toText`）へ移し、開始画面とコンテキストメニューで共有した
- GitHub 上の人のレビューは 0 件。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した
  - `get_reviews` には Copilot の review が 1 件あり、指摘は 0（Approval recommended）
  - コメントは、自分で投稿したテストケース表と bot の投稿（Storybook プレビュー・CI レポート・VRT）だけ
- CI は全件緑。VRT は差分 0。New の 1 件は足した `OnWindows` ストーリー
- セッション中に、オーナーからコンフリクトの修正を 1 回指示された（指摘 16）
