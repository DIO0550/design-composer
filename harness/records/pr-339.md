# PR #339 🐛 [Bug fix]: #156 スキーマデフォルトが指すトークンの dangling を検出する

- マージ日: 2026-08-28
- 関連 Issue: #156
- 差分規模: 20 ファイル / +294 -35

## ゴールと結果

スキーマデフォルトが指すトークンを削除したら、そのノードの prop に `dangling-token` が出る
ようにする（明示設定した参照と同じ kind・同じ綴りで）。**達成した。**

`PropDefinitionRecord.collectErrors` が `Props.toAssignments(props)` だけを走査しており、
`typography` を書いていない Text（デフォルトの `body` が効く）から `body` を消しても
`dangling-token` が 1 件も出なかった。`docs/04-tokens.md`「スキーマデフォルトとの関係」が
「デフォルト解決は dangling 参照となり、通常のバリデーションエラーとして検出される
（特別扱いしない）」と定めているのに対する食い違い。

`Used by`（`collectRefPropNames`）をデフォルト解決後へ広げるかは独立してマージできるため
#337 へ分離した。この PR は検証側だけを広げ、参照を数える側は据え置いている。
