## ゴールと結果

ゴールは「`DocumentIpcFake.changeExternally` の `path` と `content` を位置で取り違えると型エラーになるようにする」こと。達成した。

- 当初のゴールは「取り違えたら型エラー」だった。plan-reviewer の指摘(指摘 1)を受けて、「位置での取り違え」に絞った。フィールドの取り違えは型では塞いでいない
- fake の引数を `{ path, content }` にし、内部の `notifyChange` は `changeExternally` の中へ畳んだ。位置引数のテスト用ラッパーは 2 本とも削除した
- GitHub 上のレビューは `get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。人の指摘は 0 件だった
  - `get_reviews` には Copilot のレビューが 1 件あったが、指摘は 0 件(Approval recommended)
  - コメントは、自分で投稿したテストケース表と、bot の投稿(Storybook プレビュー・CI レポート・VRT)だけ
- CI はすべて緑。VRT は 209 件すべて差分なし
