# PR #1217 widthMode / heightMode を書いていない Ellipse にリサイズハンドルを出す

- マージ日: 2026-10-31
- 関連 Issue: #1176
- 差分規模: 7 ファイル / +290 -84

## ゴールと結果

ゴールは「widthMode / heightMode をファイルに書いていない Ellipse（スキーマ既定 `fixed`）を選んだとき、リサイズハンドルが出て、ハンドルでリサイズできる」。達成した。

原因は、ハンドルの出し分けがスキーマ既定を当てずに生の props を読んでいたこと。既定を当てて固定長を読む導出は、`design-document` の非公開関数 `axisLengthOf` が既に持っていた。それを `DesignDocument.fixedLengthOf` として公開し、ハンドル側もそれを通す形にした。あわせて、スキーマに無い `widthMode` を書いた Text とスキーマに無い type のノードはハンドルを失う（意図した振る舞いの変化）。

続きとして、`Size` の長さの読み出しが既定を当てる前の props を型の上で受け取れる件を #1221 に分けた。
