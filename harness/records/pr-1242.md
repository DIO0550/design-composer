# PR #1242 artboard で効かない prop の扱いを docs とコメントで「読み捨てる」に揃える

- マージ日: 2026-11-01
- 関連 Issue: #1056
- 差分規模: 7 ファイル / +151 -25

## ゴールと結果

ゴールは、docs/03 が artboard について「受け付けない」と書いていた prop の扱いを、実装と同じ語で読めるようにすることだった。対象は配置の 5 prop・ロック・回転・サイズのモードと長さ・最小 / 最大の 6 種類。実装の扱いは、パネルに出さない・書いても効かない・未知の prop のエラーにしない・ドメイン違反はエラー、の 4 点。

達成した。「読み捨てる」の定義を docs/03「前提」に 1 回だけ置き、docs/01・コメント・テスト名を揃え、テストを 8 件足した。コードの振る舞いは変えていない。

Issue は最小 / 最大だけを挙げていたが、フェーズ 1 の実測で 6 種類すべてが同じ食い違いを持つと分かった。どちらへ揃えるか(エラーにする / docs を直す)と範囲をオーナーに確認し、「docs を直す + 6 種類すべて」で進めた。
