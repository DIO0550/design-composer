## ゴールと結果

ゴールは達成した。`insertNode` / `insertArtboard` / `replaceNode` は、単一名前空間に新しい重複を作る編集を `duplicate-name` で返す。既に重複している名前は、その編集で出現が増えない限り通す。
Issue が挙げていた仕様の判断（何を「壊す」とするか）は、docs/03 の「編集は続けられる」から「編集後に重複が 1 つでもあれば err」が消えるので、回答待ちにせず決めた。理由は Issue に残した。
GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認し、コメントは bot の投稿と自分のテストケース表だけだった。CI は初回から緑で、VRT は差分なし（179 件）。
