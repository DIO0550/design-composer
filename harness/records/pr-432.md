# PR #432 キーボードからの操作を 3 つ足す（Esc で選択解除 / ⌘] ⌘[ で重なり順 / 矢印キーで座標移動）

- マージ日: 2026-09-05
- 関連 Issue: #414 / #417 / #413（いずれも #373 から分離した 21 件のうちの 3 件）
- 差分規模: 27 ファイル / +1041 -30（19 コミット）

## ゴールと結果

3 本とも**既にあるドメインの操作へキーボードの導線を足す**もので、新しい編集は増えていない。

- #414: Esc でノードの選択が外れる（トークンの選択は残す）
- #417: ⌘] / ⌘[ で選んでいるノードが兄弟の並びの中を 1 つ動く
- #413: 矢印キーで選んでいる絶対配置のノードが 1px（Shift で 10px）動く

3 本とも達成した。人のレビューは 1 件で、1 回の push で解消している。

**#419（Shift+1 / Shift+2 のズーム）は入れなかった。** `CanvasView` が画面の大きさを持たない・
`Artboard.canvasPosition` が省略可能で「全体」の範囲がドキュメントだけからは決まらない・倍率が
変わるので VRT に差分が出る、の 3 点で規模が違う。調査結果は #419 に残した。
