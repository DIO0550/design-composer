# PR #604 Box に折り返し（wrap）を足す

- マージ日: 無し（2026-09-19 に**重複としてクローズ**。同じ Issue を実装した #602 が先にマージされた）
- 関連 Issue: #595（#430 の分割）
- 差分規模: 13 ファイル / +169 -30

## ゴールと結果

ゴールは「`layout: row` / `column` の Box に折り返すかどうかを書けて、書いたときだけ
`flex-wrap` が出る」。実装・検証・CI はすべて通ったが、**成果は 1 行も main に入っていない。**

#595 は同じ時間帯に別のセッションが実装し、#602 が 02:33Z にマージされた。#604 はその
重複で、実マージを試すと 5 ファイルで衝突する（`docs/01-file-format.md` /
`docs/03-schema.md` / `compiled-element/index.ts` / `layout/index.ts` /
`primitive-schema/schema/index.ts`）。衝突を解消しても同じ機能の実装を 2 つ突き合わせる
作業にしかならないため、マージせずクローズした。

**両実装の差は 1 点だけ。** prop の位置（`layout` と `gap` の間）・値（`nowrap` / `wrap`）・
既定（`nowrap`）・有効条件（`FlexOnly`）・宣言の位置（向きの宣言の直後）はすべて一致し、
違いは語彙と既定値の出どころだけだった（#602 はスキーマ直書き + コンパイル層のローカル関数で
2 箇所、#604 は `src/domains/dcmp/wrap/` からスキーマが導出して 1 箇所）。
