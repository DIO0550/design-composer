## ゴールと結果

ゴールは達成した。リサイズハンドル（帯・ハンドルの両経路）を ⌘ / Ctrl を押しながら動かしている間は、掴んだ辺が揃え先へ吸い付かない。押しているかはポインタが動くたびに見るので、同じ掴みの中でキーを離せば吸い付き、押せば外れる。
GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。コメントは bot の投稿（プレビュー・カバレッジ・VRT）と、自分が書いたテストケース表だけ。
CI は初回から緑で、VRT は差分なし（181 件）。
