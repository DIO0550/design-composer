## うまくいったこと

- **フック不発の切り分けができた。** PR #205 でカナリアの `jq` 依存が外れたおかげで、
  「スクリプトへ直接 JSON を流すと deny が返るのに、ツール経由の `echo hook-canary` は通る」
  という形で、フェイルオープンではなく `.claude/settings.json` の配線が読まれていないことを
  確定できた。従来は両者が同じ見え方になっていた
- **`core.hooksPath` が未設定であることに気づき、`set-hooks-path.sh` を実行した。**
  リモート実行環境はクローンからやり直すため `postCreateCommand` が走らず、層 2 も
  抜けたままだった。配線後の push では git hooks が実際に走っている
- **層の選択に消去法の根拠を書いた。** 「規約に置く」ではなく「層 1・層 2 は痕跡が
  残らないので検査できず、層 3 は配線が読まれない環境で止まる。だから層 4 しか残らない」
  という形にしたので、次に読む人が層を上げる余地の有無を判断できる
