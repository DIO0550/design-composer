# PR #588 ノードの回転を指定できるようにする

- マージ日: 2026-09-18
- 関連 Issue: #427
- 差分規模: 18 ファイル / +270 -13

## ゴールと結果

ゴールは「`.dcmp` のノードに角度を書くと、その角度で回った状態でキャンバス・出力 HTML に
描かれる。プロパティパネルからも角度を変えられる」。達成した。

Issue が「判断が要る点」として挙げていた **「誰が持つのか」（絶対配置の子だけか / すべての
ノードか）は、Issue 本文が指定した判断軸（#370 の「ア」）から導いて「すべてのノードが持つ」
で決めた。** 「ア」が言っているのは「読み捨てられる値をファイルに載せない」で、フローの子が
`x` / `y` を持たないのは書いた座標が効かないため。回転はフローの子でも `transform: rotate()`
が効くので同じ理由が成り立たない、という導出。

**ゴールとのずれ: 計画段階で、この差分が既存のドラッグを壊すことが分かった。** 回転は
コンパイル結果の**インライン** style に出るので、運んでいるノードをずらして見せる `<style>`
規則の `transform:translate(...)` と同じプロパティを奪い合い、インライン側が勝つ（＝回転した
ノードを掴んでも動かない）。ずらして見せる側を個別プロパティ `translate:` へ替える修正を
同じ PR に入れた（スキーマだけ入れて描画が追いつかない形を避ける、という #379 の分割判断と
同じ理由）。
