## ゴールと結果

ゴール（着手した Issue が既に他の PR で閉じられている／Issue 自身が既にクローズされている場合に、PR を開いた直後に気づける）は達成した。
Issue の逆向きの一覧（`closedByPullRequestsReferences`）から merged の相手を拾い、閉じる Issue の `state` を見てクローズ済みを知らせる。判定では赤にしない設計は変えていない。
計画検証を受けて、逆向きの一覧からは open の相手も拾い、open な PR の一覧（100 件まで）の外にいる相手も見えるようにした。
セッションから GraphQL を叩けなかった。フィールド名は PR 自身の `duplicate-issue-pr` ジョブが初回で緑になったことで確かめた。
GitHub 上の人のレビューは 0 件。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。`get_comments` にあったのは、bot の投稿（プレビュー・カバレッジ・VRT）と自分のテストケース表だけだった。
CI は初回から緑。VRT は差分なし（181 件）。
