### 1. 「循環しない」の根拠に直接の import しか見ていなかった

- 分類: `dependency`
- 出どころ: `レビュー（plan-reviewer）`
- 内容: 計画は `TokenRefs` を `primitive-schema` の `TokenKindList` へ広げる形で、「`primitive-schema` は `css-declaration` を import していない」を根拠に循環しないと書いた。実際は `css-declaration → primitive-schema → schema → layout / visibility → css-declaration` で推移的に閉路になる。`import-rule-violations.py` は型だけの import も同じグラフへ入れるので `import type` でも逃げられない。
