# PR #958 テストヘルパーの重複を push 前と CI で src 全体を見て止める

- マージ日: 2026-10-03
- 関連 Issue: #309
- 差分規模: 13 ファイル / +261 -88

## ゴールと結果

ゴールは「`src/` のどこかにテストヘルパーの重複が 1 組でもあれば、触ったファイルかどうかに関わらず push と CI が止まる」。達成した。
- 3 つの層(PreToolUse・git hooks・CI の `rules-check`)すべてに `duplicate-test-helpers.py --all src` を載せた。
- CI のログで、`rules-check` の「テストヘルパーの重複」ステップが出て通ったことを確かめた。

計画の外で次の 3 つも入った。いずれも実装の検証の指摘による。
- `lib/pre-push-detector.sh` に `deny_on_all_src_failure` を足して共通化し、`pre-push-doc-comments.sh` も移した。
- 判定表に `check_all` を足した。
- `lib/pre-push-detector-cases.sh` を新設した。

追加行だけを見る既存の検査の撤去は #954 へ分けた。

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。コメントは、自分が投稿したテストケース表と bot の投稿(Storybook プレビュー・CI レポート・VRT)だけだった。CI は 8 件すべて緑で、VRT の差分も 0 件だった。
