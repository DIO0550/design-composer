# PR #1247 親に引き伸ばされていた Text を包むとき、Box も同じ向きに fill にする

- マージ日: 2026-11-01
- 関連 Issue: #986
- 差分規模: 11 ファイル / +617 -222

## ゴールと結果

ゴールは「⌘G で Text を Box に包んでも、親（Box / artboard）が `row` / `column` かつ既定解決後の `align` が `stretch` なら、包む前と同じく交差軸方向に引き伸ばされたままになる」。column の親と、兄弟をまとめて包む経路では達成した。

ずれが 1 つ残った。row の親で Text を 1 つだけ包むと、Box の高さは `fill` になるが Box の中は既定の column なので、Text 自身の高さは中身の高さになる（選択枠が短くなる。字面は変わらない）。#527 の「子が 1 つなら親の並べ方を写さない」と衝突するので許容とし、`docs/06-ui.md` の「包んでいる間に見た目が変わるもの」に書いた。オーナーの判断を #986 で求めたまま、回答のないまま PR はマージされた。

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。`get_reviews` には Copilot のレビュー 1 件があった（指摘 15）。コメントは、自分が投稿したテストケース表と bot の投稿（Storybook プレビュー・CI レポート・VRT）だけ。CI は全件緑で、VRT の差分は 0 件だった（204 件 passed）。
