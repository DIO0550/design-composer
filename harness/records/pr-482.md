# PR #482 [ui] 右クリックでコンテキストメニューを開けるようにする（器の実装）

- マージ日: 2026-09-12
- 関連 Issue: #470（親 #418）
- 差分規模: 41 ファイル / +2570 -103

## ゴールと結果

キャンバスで右クリックすると、その対象に対してできる編集操作がメニューに並び、押すと
キーボードの割り当てと同じ編集が起きる。キーボードだけ（↑↓ / Enter / Esc）でも操作でき、
できない操作は消えずに押せない状態で並ぶ。達成した。

ゴールからずれたものは 3 つ割り出した（#479 ツリーの受け口 / #480 割り当ての綴りを OS に
合わせる / #481 メニューから部品にする）。うち #480 と #481 は計画の検証で割った。

検証は `plan-reviewer` が 14 件（うち 3 件は私が計画に書いた事実の誤り）、
`implementation-reviewer` が 7 件（うち 4 件は私が差分に書いた事実の誤り）を出し、いずれも
すべて受け入れた。そのうえで**人のレビューが 4 件**届いており、サブエージェントは
Composition・キーの語彙・コメントの過剰を 1 件も捕まえていない。
