## ゴールと結果

Issue は「リサイズと artboard の移動でも隙間の数値を出すか決める」で、仕様(`docs/06-ui.md`)と UI 案のどちらからも決まらないため、フェーズ 1 で止めてオーナーに選択肢を出した。案 C(artboard の移動は出す / リサイズは出さない)の回答を受けて、ゴールを「artboard の移動中に揃ったとき隙間が数値で見える / リサイズは線だけのままで、docs から未決が消え出さない理由が書かれている」とした。達成した。

コードの変更は描く側の差し替え 1 か所(`GuideLineOverlay` → `SnapGuideOverlay`)だけで、`ArtboardDrag.snapGuides` は前から `gapLine` を持っていた。GitHub 上の人のレビューは 0 件(`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認。コメントは自分のテストケース表と bot の投稿だけ)。CI は全件緑、VRT は差分 0 件(202 件 passed)。
