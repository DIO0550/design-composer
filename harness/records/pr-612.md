## ゴールと結果

ゴールは「`gradients` 種別の値の形式・参照のしかた・名前衝突の扱いが docs に書かれ、実装
Issue（#607 / #608 / #609）が docs だけを見て進められる状態になる」こと。達成した。

**ゴールとのずれ: Issue 本文が `docs/01-file-format.md` の表を「決めて反映する」対象に
挙げていたが、変更しない側に倒した。** 表へ足すのは「アプリが読み書きできるようになった
時点」という運用が `03-schema`「Ellipse」に実在し（`grep -rn "Ellipse" src` は 0 件で表にも
無い / `rotation` は実装済みで表にある）、docs だけのこの回で足すと表が版の意味を失うため。
本文と形が変わる点は Issue へ明記した。

**決めたのは 3 + 1 件。** Issue 本文が挙げた 2 件（stop の色 / 名前衝突）に formatVersion を
加えた 3 件に、`plan-reviewer` の指摘で「初期テーマに `gradients` を 1 件入れる」が増えた。
