# PR #1387 中身の変わらない編集を undo 1 回ぶんに数えない

- マージ日: 2026-11-15
- 関連 Issue: #1379
- 差分規模: 15 ファイル / +407 -14

## ゴールと結果

ゴールは次のとおり。値を変えずに入力欄から離れても、変化の無い編集が undo の履歴に積まれない。Ctrl+Z を 1 回押せば必ずドキュメントの中身が 1 段変わる。

達成した。判定は履歴の側(`EditHistory` の `record` / `undo` の入口)に置き、中身の比較は `DesignDocument.isSameContent`(`toJson` どうしを `Json.equals`)にした。中身の変わらない編集で redo が捨てられる点は #1384 に切り出した。判断待ちで止めた回は無い。

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。`get_reviews` の DIO0550 の 2 件は、Devin のスレッドへ自分が返した返信が載ったもの。`get_comments` の DIO0550 の 1 件は、自分が貼ったテスト表。bot のレビューは Devin の 1 件(指摘 2 件)と Copilot の概要 1 件(open issue 0 件)。CI は全件緑で、VRT の差分は 0 件(209 件 passed)。
