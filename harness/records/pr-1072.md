## ゴールと結果

ゴールは「検証するという動作だけで立っているモジュール `design-document/validation/` を無くし、違反を集める走査は `DesignDocument` 本体、違反をエラーの形にする詰め替えは `DesignDocumentValidationError`(`validation-error/`)が持つ。`collectErrors` の出力は変えない」。達成した。

出力を変えていない証拠として、移動の前に `validate-error-shape`(エラー配列全体を `toStrictEqual`)と並びのテストを足し、移動前のコードで緑を確かめてから動かした。GitHub 上の人のレビューは 0 件(`get_review_comments` / `get_reviews` は空、`get_comments` は bot 3 件と自分のテスト表 1 件)。CI はすべて緑、VRT は差分 0(194 件)。

Issue アサインで起動したルーチンのセッションで実装した。Issue には作成側のセッションの「着手」コメントが先にあったが、そちらは実装を進めておらず並行作業にはなっていない。
