## フックの発火

**このセッションでは `.claude/hooks/` のフックが 1 つも発火しなかった。** push 前に `echo hook-canary` を実行したところ deny されずそのまま通ったため、フック不発環境と判定した（`.claude/hooks/README.md`「フックが発火しない実行環境がある」）。PR 本文にもその旨を記載した。

push 前検査の enforcement は git hooks（`harness/githooks/pre-push`）が担っており、`git push` 時に typecheck / oxlint / biome / doc コメント / テスト規約がすべて実行されて通過したことを出力で確認している。

## うまくいったこと

- **push 前の検査を `&&` で連ねず 1 つずつ独立に実行した**ことで、oxlint が 0 件のまま biome の format 差分（2 ファイル）を検出できた。連ねていれば末尾しか見えず、PR #124 / #168 と同じく format 差分のまま push して CI を落としていた
- **疑わしい assert を頭で判断せず、実際にミューテーションを入れて確かめた**。ガードを外す / 誤って止める方向の両方を試し、「止める」4 判断と「止めない」3 判断がすべてテストで守られていることを確認できた。指摘 6・7 の空振りはこの手順でしか見つからなかった
- **実装前に再現テストを書いて、バグが実在することと壊し方を確認した**（確認後に削除）。「壊れた内容がシリアライズ済みドキュメント全文で上書きされる」ことを目で見てから計画に入れた
- **Issue が未決としていた判断を、当時と今で前提が変わっていないかから確かめた**。#135 の完了と UI 案の記述という一次の根拠に当たったことで、回答待ちで止めずに済んだ
