## ゴールと結果

ゴールは「`use-text-edit` の `start` が、名前から矩形を組み立てるのに `DrawnBounds.measure` を
通っている状態」。`Option.map(CanvasDom.elementOf(name), CanvasBounds.ofElement)` が
`DrawnBounds.measure` と `use-text-edit` の `start` に独立して書かれていた
（`rules/coding.md`「同じ処理が2箇所に現れたら共通化する」）。

達成。振る舞いは変えていない（公開 API・`TextEditAction` の直和とも不変で、呼び出し側 5 ファイルは
無変更）。完了の確認は
`grep -rn "CanvasDom\|CanvasBounds.ofElement" src/features/canvas/hooks/use-text-edit/` = 0 件。

ゴールとのずれ: **初出のゴール文「同じ組み立てが 2 箇所に無い」はこの PR だけでは成立しない**。
`use-node-drag` の `boundsOf`（`index.ts:123-125`）が `DrawnBounds.measure` と本体一致のまま残り、
#569 へ分離した（指摘 1）。計画の段階でゴールを「`use-text-edit` の `start` が通る／
`use-node-drag` の同形は #569 で残す」へ狭めた。
