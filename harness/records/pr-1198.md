# PR #1198 [ui] 複数選択中のコピー / 複製を、最上位だけを写す形で有効にする

- マージ日: 2026-10-27
- 関連 Issue: #1186
- 差分規模: 32 ファイル / +1200 -585

## ゴールと結果

複数選択中に ⌘C / ⌘D(とコンテキストメニューの同じ行)が使えるようになる。対象は選択の最上位のノードだけで、複製はそれぞれ元の直後に置いてまとめて選び、取り消し 1 回で全部戻る。コピーは複数のサブツリーを持ち、1 つだけ選んだときのペーストで全部を貼る。複数選択中のペーストと、artboard が混ざった選択のコピー / 複製は無効。達成した。人のレビュー指摘は 0 件、bot(Copilot)の概要レビューも指摘 0 件、CI は 1 回目で緑。
