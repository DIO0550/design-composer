## 手戻り

計画から外れたのは指摘 11（未決の判断の撤回）と、それに伴うストーリー 1 本の追加。以下は実装中に自分で踏んだもの。

- **フィクスチャの初版で assert が 2 件になった。** `danglingTokenDocument` にトークン一式を入れていなかったため、スキーマが既定値で指すトークン（Text の `color: "gray-900"`）まで dangling になり、確かめたい 1 件が埋もれた。雛形のトークンを入れて解消。#156 が指している穴と同じ形がフィクスチャ側で出た
- **往復テストで `toStrictEqual` が落ちた。** JSON を経由すると省略可能なキー（`props: undefined`）が落ちるため。既存の `opened-document.normal.test.ts` が同じ理由で `toEqual` を使っていたので揃えた
- **`biome check` が 2 回落ちた**（文字列の折り返し / import の並び）。どちらも `--write` で解消。同じ回に `oxlint` は 2 回とも 0 errors で、2 つが別物であることが実際に出た
- **`git checkout --` でミューテーションを戻したとき、同じファイルにあった自分のコメント修正まで巻き戻した。** 未コミットの変更があるファイルを実測に使うときは、先にコミットしておくか戻す範囲を絞る必要がある
- **依存関係が未インストールの状態から始まった**（`node_modules` が無く、最初のテスト実行前に `pnpm install --frozen-lockfile` が要った）
