# PR #455 クリックでいちばん外側を選び、ダブルクリック / ⌘ + クリックで掘れるようにする

- マージ日: 2026-09-08
- 関連 Issue: #412
- 差分規模: 27 ファイル / +843 -106（4 コミット）

## ゴールと結果

キャンバスのクリックが artboard 直下の子を選び、ダブルクリックで 1 階層ずつ掘れ、⌘ + クリックで
押した位置のいちばん内側を直接選べるようにする。掘りきった Text はこれまでどおりダブルクリックで
インライン編集に入る（#412 / #373 A3）。

**達成した。** Issue が「両方が決まるまで実装単位に割れない」としていた 2 つの未決（インライン編集の
移し先 / `docs/06-ui.md` への書き足し）は、選択肢と根拠を Issue に出して回答を待ってから実装に入った。

**規則そのものは検証の途中で作り直した。** 当初の「クリックは常にいちばん外側」は、ダブルクリックの
前に `click` が 2 回届くため 2 階層より内側へ入れない（下記 指摘 1）。「クリックは掘った状態から外へ
戻さない」を規則に入れる形へ変え、`event.detail` に依存しない設計にした。

人のレビュー・CI の失敗はどちらも 0 件（`get_review_comments` / `get_reviews` / `get_comments` の
3 つとも引いて確認。`get_comments` の 3 件はすべて `github-actions[bot]`）。CI は初回から全 6 チェックが
緑、VRT も差分 0（新規ストーリー 1 件）。指摘はすべてサブエージェント由来と自己修正。

### 1. click が 2 回先に届くので、掘った選択が毎回リセットされる設計になっていた

- 既存ルール: `.claude/skills/implementation-flow/SKILL.md` フェーズ 3 手順 3（想定した前提が実例で
