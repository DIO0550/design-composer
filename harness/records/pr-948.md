## ゴールと結果

当初のゴールは「背景起動の経路を、手順ではなくフックで塞ぐ」だった。実装の検証を受けて、「`run_in_background: true` を明示した起動の入口を塞ぐ」まで縮めた。縮めたゴールは達成した。`false` を渡しても実行環境が背景で起動する経路と、実行中に背景へ移す経路は塞いでいない。どちらも #944 へ移した。
Claude Code が PreToolUse の `tool_input` に `run_in_background` を載せるかと、Agent への deny が起動を止めるかは実測できていない(このセッションではプロジェクトのフックが発火しなかった)。

CI は 8 件すべて緑で、VRT の差分も 0 件だった。
