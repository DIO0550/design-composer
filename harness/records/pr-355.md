## ゴールと結果

`pnpm run lint` が出していた「domains は libs を import できません」の警告 5 件を 0 件にし、
`.oxlintrc.json` の `src/domains/**` override を `warn` から `error` へ上げる。達成した。

ずれは無い。production の違反（`DocumentSaveState` が IPC の失敗型をそのまま持っていた）は、
ドメイン側に語彙を作り `libs/document-ipc` が境界で詰め替える形（腐敗防止層）で解消した。
開く経路に語彙が 2 系統残る件は #354 へ分離した。

**ゴールの確定で 1 度停止している。** Issue 本文が「選択肢（未決・判断をお願いします）」の
ままで、A / B / C は成果物が違った（C は差分 0、A は 12 ファイル、B は A + lint 設定 + 規約）。
実装へ進まず、選択肢と根拠・セッション URL を Issue へ書いて回答を待った。回答は「推奨（B）で。
ちゃんと境界を作って、腐敗防止層とかを考えられてればおk」。
