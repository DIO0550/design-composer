# PR #1241 locking を publicProps の binding の宛先にすることを禁止する

- マージ日: 2026-11-01
- 関連 Issue: #1189

## ゴールと結果

ゴールは、publicProps の binding の宛先 prop が(プリミティブの)`locking` のドキュメントを開くと、binding の不整合としてエラー一覧に出ること。ファイルは開き、編集は続けられる。そうした binding を UI から作れる経路があれば、その扱いも決める。ゴールは達成した。

- 判定は `ComponentBinding.hopIntoPrimitive` の 1 か所に置いた。エラー一覧への表示と、インスペクタの公開 prop 欄を消すことが、同じ判定で揃う
- UI からこの binding を作る経路は無い。手当ては要らないと計画で確かめた
- GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確かめた。コメントは自分のテストケース表と bot の投稿だけだった
- bot のレビューは Copilot の 1 件で、「Approval recommended / No open issues」だった。指摘は無い
- CI は 9 本すべて緑だった。VRT の差分は 0 件(204 passed)。テストは 691 files / 5427 tests
