## ゴールと結果

ゴールは達成した。「選択中のトークンと違う種別の値を渡すと `none` になり、同名の別種別のトークンは書き換わらない」を
テストで固定した。種別の照合は `Token.withValue` に置き、`EditorState.setTokenValue` はそれを通して組み立てる。
型で閉じる案は、選択が実行時の `Option<TokenRef>` なので採らなかった（Issue #753 の却下案）。
人のレビュー指摘は 0 件（`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認。コメントは bot の投稿と自分の報告だけ）。
