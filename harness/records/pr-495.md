- **`plan-reviewer` の指摘 3（artboard の理由が事実と違う）を、計画の段階で直せた。** 実装へ持ち込んでいたら、コメントと docs の 3 箇所に嘘の理由が入ったまま PR に出ていた

## 規約への反映

**無し。** 20 件すべて既存の規約・観点に対応があり、書かれていない判断基準は出ていない。回数を数えて介入するかを決めるのは `harness-growth` の管轄なので、ここでは数えない。

`comment-structure-claim`（指摘 16）だけは既存語彙にぴたりと当たらない形（**先行モジュールから転記した注記が、転記先では成立しない**）だが、1 回目なので語彙は増やさず既存の分類に入れた。
