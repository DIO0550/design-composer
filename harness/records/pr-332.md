## ゴールと結果

README を読めば、design-composer が何のアプリかと、開発の始め方・仕様書とハーネスの入口が
分かる状態にする。**達成した。**

**Issue 本文が空だった。** タイトル「README.mdの更新」だけからゴールを立てている。
「README を design-composer の README にすることであって、特定の節を書き足すことではない」
という仮定を Issue に明記したうえで進めた。現 README は 129 行すべてがテンプレート
リポジトリ（`tauri-devcontainer-template`）のもので、見出しが `# tauri-devcontainer-template`、
使い方が「Use this template でコピー」から始まり、Rust 側を「`pnpm tauri init` で初期化します」
と書いている（実際は `tauri.conf.json` に `productName "Design Composer"` と `.dcmp` の
関連付けまで入っている）状態だったため、**どの解釈を取っても直す必要がある部分**から着手した。

テンプレート由来のまま残っているものが他にも 6 件見つかったが、README と独立してマージできる
ため #331 へ分離した（`package.json` の `name` / `src-tauri/Cargo.toml` のメタデータ /
`TAURI_SETUP.md` のテンプレート前提の記述 / `greet` コマンド / `public/*.svg` /
`docs/05-architecture.md` の `src/core/` `src/ui/` の陳腐化）。
