## ゴールと結果

ゴールは達成した。選んでいるノード 1 つを ⌘D / Ctrl+D とコンテキストメニューの `Duplicate` で複製できる。複製は同じ親の直後に入り、名前は自動リネームで付け替わり、選択は複製へ移る。
Issue が「判断が要る点」としていた複製先は「同じ親の直後」（Figma と同じ）に決め、`docs/06-ui.md` に書き足した。
ずれは 1 点。計画では連打で `title-3` になると書いていたが、既存の自動リネーム規則では `title-2-2` になる。規則は変えず、#858 に切り出した。
GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。コメントは bot の投稿（プレビュー・カバレッジ・VRT）と自分のテストケース表だけ。Copilot のレビューは所見 0 件。
CI は初回から緑で、VRT は差分なし（181 件）。
