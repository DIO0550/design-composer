## ゴールと結果

ゴールは 2 つあり、どちらも達成した。

- アイコン系のボタン 7 個が基本ボタンの種類「アイコン」で描かれ、画面ごとの className で描かれていない状態になる
  - 上部バーの倍率 `−` / `+` と stop の `+` / `−` は Icon(26px・枠なし・灰の字)にした
  - 倍率表示 `55%` と一覧の見出しの `+` 2 個は、新しく足した InlineIcon にした
- `src/components/` の外で生の `<button>` を新しく書くと、検査で落ちる状態になる
  - `.oxlintrc.json` に `react/forbid-elements` を入れた
  - 許可はファイル単位で、許可したファイルの中の穴は恒久の判断として README に書いた

Issue 本文の対象は 9 個だったが、利用者の判断でツールバーのスロット 2 個を外し、7 個にした。

判断待ちで 2 回止めた。

- 1 回目は、着手の時点で Issue 本文に残っていた未決 2 点
- 2 回目は、計画と plan-reviewer の後に新しく出た 4 点
- 回答はどちらも「おすすめで」

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。コメントは、自分が投稿したテストケース表と VRT の説明、それに bot の投稿(Storybook プレビュー・CI レポート・VRT)だけ。

CI は、VRT が意図した差分(Changed 10 / New 1)で一度赤くなった。ほかはすべて緑。`visual-approved` が付いてマージされた。

hover の配色(タブバーの値 `#f0f0f0` を借りた)は、利用者に確認しないまま PR 本文の確認事項に挙げた。覆す指摘は無いまま、マージされた。
