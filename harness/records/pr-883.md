# PR #883 ツリー（Layers / Artboards 一覧）の右クリックでコンテキストメニューを開けるようにする

- マージ日: 2026-09-28
- 関連 Issue: #479
- 差分規模: 37 ファイル / +584 -91

## ゴールと結果

ゴールは達成した。`Layers` のツリーの行ではノードのメニュー、`Artboards` の一覧の行では artboard のメニューが、右クリックで出る。選択に入っていない行ならその行だけを選び、複数選択の一員の行では選択を保つ（`EditorState.selectIfUnselected`）。
あわせて、並べ替えのドラッグを主ボタンでしか掴まないようにした。右クリックでメニューが出ると、行が掴まれたまま残っていたため。
人のレビューで受け口の形が 2 回変わった。`RowContextMenuEvent` と `LeftPaneContextMenuActions` の組から、`ClientPoint` と既存の Actions 型の組になり、最後に `ClientPoint` を消した。
CI は 3 回の push すべてで緑だった。VRT は差分なし（181 件）。人のレビューは `get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。レビュー本文は空で、指摘は 2 スレッドにある。
