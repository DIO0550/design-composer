## ゴールと結果

ゴールは、祖先だけが回っている(自分は回っていない)ノードをキャンバスで運んだときに、次の 3 つが揃うこと。360 度の倍数・回っていない祖先の中の振る舞いは変えない。

- 離した後の x / y が親の座標系で書かれ、画面上でポインタの向き・量だけ動く
- 寄せ量も親の座標へ戻して書かれる
- 運んでいる最中の `translate` がポインタに付いてくる

達成した。Storybook + Playwright の実ブラウザで、運んでいる最中と離した後の両方を確かめた。仕様(06-ui)に答えの無い 3 点(付け替えで何を保つか / 回った揃え先の辺 / キーとドラッグの向き)は、計画の検証の後にオーナーへ確認して止め、回答「推奨でいい」で再開した。
