# PR #651 padding / radius の畳み方を択一のセグメントで選べるようにする

- マージ日: 2026-09-20
- 関連 Issue: #614
- 差分規模: 10 ファイル / +278 -161

## ゴールと結果

ゴールは「padding / radius の束ねた行で、畳んだ欄と longhand ごとの欄のどちらを出すかを、
押下トグル 1 つではなく択一のセグメントで選べる。選んでいる側が常にどちらか 1 つ見えていて、
選んでいるセグメントをもう一度押しても未選択に落ちない」。達成した。

**ゴールの外に 2 つ出た。** 1 つは `src/components/segmented-control` を Composition へ
組み替えたこと（択一に未選択が無いことを型で表すため。押し直しの解釈を呼び出し側へ移した）。
もう 1 つは `prop-row` の `sr-only` が本文のスクロール枠を抜けて文書を伸ばしていた既存の
不具合で、この行が 1 段高くなったことで撮影範囲の閾値を越え、CI で顕在化して直した。

綴りは計画で日本語（`まとめて` / `辺ごと` / `隅ごと`）に決めたが、レビューで英字
（`all` / `sides` / `corners`）へ変えた。
