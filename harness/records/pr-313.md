# PR #313 ✨ #209 キャンバス下端の帯から reveal in tree でツリーへ飛べるようにする

- マージ日: 2026-08-25
- 関連 Issue: #209

## ゴールと結果

キャンバス下端の帯（#147）から `reveal in tree` を押すと、破線が掛かっているノードの先頭が
選択され、左ペインが `Layers` へ切り替わってツリーのその行が選択状態で見える。**達成した。**

ゴールからのずれが 1 つある。Issue 本文は飛び先を「参照元の先頭（`collectTokenReferrers` の
並び）」と書いていたが、実装は `collectCanvasReferrerNames` の先頭を使った。artboard 自身が
そのトークンを参照しているときだけ両者がずれ、artboard には破線が掛からず（`TokenReferrer.nodeNames`
が落とす）ツリーの行でもない（#112）ので、帯の名乗り `N nodes · dashed in canvas` と完了条件の
両方に合わないため。計画の時点で Issue に理由付きで書き、`plan-reviewer` も一貫していると判定した。
