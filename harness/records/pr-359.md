# PR #359 参照元の収集をスキーマデフォルト解決後へ広げる

- マージ日: 2026-08-29
- 関連 Issue: #337
- 差分規模: 12 ファイル / +378 -28

## ゴールと結果

`Used by` の件数・行が、そのトークンを削除したときに `dangling-token` になる参照とすべて
一致すること。スキーマデフォルトで効いている参照も数え、キャンバスの破線（#147）も同じ
範囲にする。

達成した。artboard だけは検証側が Box スキーマを照らすため照らす先が 2 通り残るが、Box の
既定がすべて enum なので今は差が出ない（この条件は `TokenReferrer.collectInArtboard` の
doc に書いた）。

Issue の「決めること」が 2 件未決だったため、着手時は実装に入らず選択肢と根拠を Issue へ
出して回答を待った。方針（案 A + 区別しない + 破線も同じ範囲へ）の確定後に計画へ進んだ。
