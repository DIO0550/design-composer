# PR #1383 回ったノードのリサイズで、掴んでいない軸が連れて変わっても反対の辺・角を留める

- マージ日: 2026-11-15
- 関連 Issue: #1027
- 差分規模: 19 ファイル / +1162 -108

## ゴールと結果

ゴール:
- 自分が回っている絶対配置のノードをリサイズしたとき、掴んでいない軸が `hug` / `fill` で長さが連れて変わっても、離したあとの結果で反対の辺・角が親の座標で留まる
- 許容は位置の丸めによる軸ごとに 0.5px 以内
- 掴んでから離すまでは undo 1 回ぶんのまま

結果: 達成した。
- 方式: 書き込む長さを要素のインライン style に一瞬当て、`getComputedStyle` で前後 2 回測る
- Chromium の実測（Storybook `RotatedHugText`）で、反対の角のずれは軸ごとに dx=−0.495 / dy=−0.356px
- WebKit は環境に無く未検証
- 位置で折り返しが変わる幅 hug は #1380 に切り出した

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。
- `get_reviews`: Copilot の bot レビュー 1 件だけ
- `get_review_comments`: 0 件
- `get_comments`: 自分が投稿したテストケース表と、bot の投稿（Storybook プレビュー・CI レポート・VRT）だけ

CI の失敗は 0 件。
