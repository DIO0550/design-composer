# PR #1329 名前が重複した文書で Box の大きさを変えたときの追従を、子の名前ではなくノードの値へ当てる

- マージ日: 2026-11-09
- 関連 Issue: #896
- 差分規模: 10 ファイル / +556 -103

## ゴールと結果

ゴールは「名前が重複した文書(docs/03-schema.md「開く時」で開いて編集を続けられる文書)でも、Box の大きさを変えたとき(`EditorState.resize` / props 欄からの `EditorState.applyPropEdit`)に、直下の絶対配置の子の追従がその子自身に当たり、例外を投げずに編集が終わる」。達成した。

同じ原因で起きていた次の 2 つも、追従を値で組む形にしたことで一緒に直った。

- 前の兄弟の子にある同名ノードが代わりに動く
- artboard と同名の子の追従が、artboard の props に書かれる

props 欄から artboard の width を変えても子が追従しない件は、この PR より前からの挙動で、スコープ外として Issue に残した。
