# PR #1436 グループ化で部品インスタンスを包むとき、部品のルートの fill と Text の引き伸ばしを Box へ引き継ぐ

- マージ日: 2026-11-22
- 関連 Issue: #988
- 差分規模: 6 ファイル / +306 -62

## ゴールと結果

ゴールは、グループ化（⌘G。1 つでも複数でも）で部品インスタンスを包んだときに、インスタンスの大きさを変えないこと。具体的には次の 2 つ。

1. 参照先の部品のルート（上書きを当てたもの）で `fill` の軸は、Box も `fill` にする
2. ルートが Text のインスタンスが `align: stretch` の親に引き伸ばされていたなら、その軸も Box を `fill` にする

どちらも達成した。ただし計画の検証で、親が `layout: free` のときは写さないことにした。写すと、正しいドキュメントが検証エラーのドキュメントに変わるため。その代わりにこの場合はインスタンスが縮むので、仕様の「見た目が変わるもの」に残した。

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。DIO0550 名義の投稿は、このセッションが貼ったテスト表だけだった。bot は chatgpt-codex-connector がコードレビューとセキュリティレビューを走らせ、どちらも指摘 0 件だった。CI は全件緑で、VRT の差分は 0 件（212 件一致）だった。
