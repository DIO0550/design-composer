## ゴールと結果

ゴールは「同じファイルを指す別表記のパス(symlink 経由と実体、絶対パス中の `.` / `//`、大文字小文字を区別しない FS での大小違い)から開いても、TS 側で同じドキュメント(同じタブ・最近使ったファイルの同じ行)として扱われる」。macOS / Windows については達成した(Rust の `canonicalize_document_path` で寄せ、`use-document-session` の 3 箇所で使う)。

ずれが 1 つある。Linux の大小を区別しない FS(casefold の ext4、vfat)では大小違いを寄せない。glibc の `realpath` が直さないためで、docs を macOS / Windows に限った(指摘 15)。Rust のテストは CI で走らず、この環境でもクレートはビルドできない。単体の rustc で linux の 11 件を通した。macOS / Windows での実行は未確認。

着手直後に、正規化の置き場所が IPC の契約を変えるため、`AGENTS.md`「設計判断の確認」に従って選択肢を挙げて止めた。オーナーの回答は「おすすめでいいよ」で、判断の承認なので指摘には数えない。GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。コメントは、自分が投稿したテストケース表と bot の投稿(Storybook プレビュー・CI レポート・VRT)だけ。CI は全件緑で、VRT の差分は 0 件だった(202 件 passed)。
