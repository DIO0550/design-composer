## ゴールと結果

ゴールは達成した。
- 名前で描画要素を引く選択子は `Css.attributeSelector` → `CanvasDom.selectorOf` の 1 箇所で組み立てるようになった。`CanvasDom.elementOf`・`NameStyleRule`・テストヘルパーはここを使う
- 1 つに定まるのは artboard とその配下のノードだけ、という前提を doc に書いた。呼び出し側がそれ以外の名前を渡さないことは Issue に表で残した
- `scanLiteral` は不在を `Option` で返す

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認し、コメントは bot の投稿と自分のテストケース表だけだった。CI は初回から緑で、VRT は差分なし（179 件）。
