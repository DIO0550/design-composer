- 範囲は本文より広がった。`useLayoutEffect` と default import 経由の `React.useEffect` も止め、移したのは 9 ファイル・11 か所になった
- 残った穴は続きの Issue に分けた。`.mts` / `.cts` が glob から漏れる件は #1445、自動保存の素の `setTimeout` は #1459、lint 抑制の許可例外の説明は #1460、非同期の開始前・途中に外れたときの後始末のテストは #1461

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。`DIO0550` の投稿は、このセッションが Devin の指摘へ返した返信だけだった。bot は、Codex のコードレビューとセキュリティレビューがどちらも指摘なし、Devin が低 1 件（指摘 2）。CI は head の check run 14 件がすべて成功し、VRT は 212 件 passed・差分 0 だった。
