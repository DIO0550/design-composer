# PR #1346 sticky コメントを貼る・差し替える処理を 1 本の共通スクリプトに集める

## ゴールと結果

ゴールは「PR へ marker 付きの sticky コメントを『探して、あれば PATCH・無ければ POST』する処理が 1 つのスクリプトに集まり、呼び出し側ごとの違いが引数か呼び出し側の終了コードの扱いで表されている」。達成した。Issue の表の 3 箇所に、表に無かった 4 箇所目(`storybook-pr-preview.yml`)を加えて `.github/scripts/upsert-sticky-comment.sh` に寄せた。違いは `--if-missing post|skip` と、呼び出し側が exit 1 だけを受け流すかどうかで表す。

Issue の文言(「探し方(ページング)を引数で表す」)からは読み替えた。1 ページ目だけの探索は二重投稿の潜在的な不具合なので、引数にせず全箇所を全ページ探索に揃えた(理由は #638 の計画コメント)。どこにも配線されていなかった `check-duplicate-issue-pr-cases.sh` を CI に配線した。

GitHub 上の人のレビューは 0 件だった。`get_reviews`・`get_review_comments`・`get_comments` の 3 つとも確認した。コメントは、自分が投稿したテストケース表と bot の投稿(Storybook プレビュー・CI レポート・VRT)だけ。CI は全件緑で、VRT の差分は 0 件だった(209 件 passed)。3 種類の sticky コメントは marker ごとに 1 件ずつ、新しい共通スクリプト経由で貼られた。
