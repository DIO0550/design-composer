## 指摘

### 1. 編集後フックの `oxlint --fix` で `prefer-const` の自動修正が `typeof` 参照する型を狭め、型検査を壊す

- 分類: `harness`
- 出どころ: `レビュー（bot）`
- 内容: Devin（[P2]）の指摘。Biome の対象外（`.storybook/` 配下など）で `let fallback = "en"; export type Locale = typeof fallback;` のように `let` を `typeof` 参照していると、`post-edit-lint.sh` の `oxlint --fix` が黙って `const` へ書き換えて型をリテラル型へ狭め TS2322 を起こす。修正パスを `oxlint --fix -A prefer-const` にして自動書き換えを除外し、直後の診断パスと `pre-push`・CI では `error` を維持する形に直した（`64ddf7a`）。
- 既存ルール: なし

## 手戻り

- 計画 v1 時点では `.claude/hooks/post-edit-lint.sh` は変更対象外で、`prefer-const` の自動修正が走る前提で `.claude/hooks/README.md` にもその挙動を書いていた。PR #1496 の Devin レビュー（指摘 1）を受けて `post-edit-lint.sh` の修正パスへ `-A prefer-const` を追加し、`README.md` の記述も実態に合わせて更新した。
