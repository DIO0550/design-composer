# PR #654 検出器を走らせられない環境で check-added-* を落とし、その挙動を判定表で固定する

## ゴールと結果

ゴールは「`check-added-lint-suppressions.sh` / `check-added-test-helper-duplication.sh` が、
検出器を走らせられない環境で『ありません』と出して exit 0 になる状態を無くし、その挙動を
判定表で固定する」。達成した。

Issue が挙げていた 3 案（`|| true` を外す / 外さない / 折衷）は**どれも採らなかった**。
実測で、検出器は**違反を見つけたときにも exit 1** を返すことが分かり、`set -euo pipefail` の
下で `|| true` を外すと違反を見つけた瞬間に検出行を出さずに止まる。Issue の「落とさない側の
根拠」が書いていた「`|| true` は 1 ファイルで落ちても走査を続けるためのもの」という読み方も
成り立っていなかった。本体は「違反があった(1)」と「検出器が走らなかった(127)」を同じ非 0 へ
畳んでいることなので、終了コードを 3 値（0 / 1 / 2）に分け、前提チェックをループの外へ置いた。

層ごとの扱いは 層 1（CI）= 落とす / 層 2（`pre-push`）= 飛ばして「飛ばします」と出す /
層 3 = 据え置き。
