## 手戻り

- 開発サーバーは実行環境のネットワークインターフェース取得制約で起動できず、静的ビルドを既定にした。既定の pnpm 11 が作った設定差分は戻し、固定の pnpm 10.33.0 で検査した。
- 計画レビューは 2 周、実装の観点別レビューは 3 周で収束。元の 7 ケースは骨組みで失敗することを確認し、ミューテーションで残った 4 ケースを後から足した。ローカルの pre-push 初回は oxlint のネスト検査と既存解説判定表の Broken pipe で失敗し、前者は関数の抽出、後者は再実行で解消した。これらは GitHub CI の失敗には含めない。
- Devin の 3 件は DOM の実際の動きに起因し、偽ドライバーの判定表では再現しなかった。実 Chrome の判定表を先に失敗させてから直し、非同期フォーカスの再確認も追加した。直接座標の操作、一部が見える要素、既存編集画面のデモも通した。
