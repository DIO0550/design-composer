# PR #516 📝 [Documentation]: #424 幅 ≠ 高さの楕円を Ellipse プリミティブで作ると仕様に決める

## ゴールと結果

`docs/03-schema.md` を読んだときに、幅 ≠ 高さの楕円は Ellipse プリミティブで作ると決まっていることと、Line / Vector は持たないことが読める状態にする。達成した。

Issue は「a（持たない）か b〜d のどれかを決めてほしい」という判断待ちの状態で割り当てられたため、フェーズ 1 で一度停止して回答を待った。示された判断軸は「Figma ができるかどうか」で、これを当てると a（Figma は `EllipseNode` で幅 ≠ 高さの楕円を作れる）も b / c（Figma の `cornerRadius` は `number | figma.mixed` で % を持たない）も外れ、d だけが残った。

実装は #514 へ分けた。UI 案（`docs/Design Composer.html`）に楕円の語彙が 0 件で、ツールバーが `Object.values(PrimitiveTypes)` を回している以上、UI 案に無いスロットと字面の判断が別に要るため。
