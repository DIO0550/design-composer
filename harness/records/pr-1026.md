# PR #1026 回転したノードのリサイズハンドルを枠ごと回し、伸びる向きと置き直しを合わせる

- マージ日: 2026-10-10
- 関連 Issue: #998
- 差分規模: 32 ファイル / +1705 -163

## ゴールと結果

ゴールは「回転したノード（自分か祖先が回っている）を選ぶと、リサイズハンドルが回った要素の角・辺の中点に出て、外向きに引くとその向きに伸びる。始点側・角を引いたときは反対の角が画面上で止まる（絶対配置）。回っていないノードは変わらない」。達成した。

範囲を 1 つ狭めた。掴んでいない軸が `hug` / `fill` で長さが連れて変わるノードでは、反対側が留まらない（solution-reviewer の指摘）。仕様に範囲を明記し、#1027 に切り出した。

計画の前に、Issue の記述同士の食い違い（「書き込む数値は合っている」と、射影が要ること）を含む未決の判断 6 点をオーナーに確認した。うち判断 6（カーソル）は、確認に添えた例（「30 度は `ew`」）が規則（最寄りの 45 度刻み）と食い違っていた。A / B の再確認には回答が無く、A（今の実装）のままマージされた。

GitHub 上の人のレビューは 1 スレッドだった。`get_reviews`（4 件。すべてそのスレッドのコメント）・`get_review_comments`・`get_comments` の 3 つとも確認した。`get_comments` は自分が投稿したテストケース表と bot の投稿（Storybook プレビュー・CI レポート・VRT）だけだった。CI は 2 回の push とも全件緑。VRT は差分 0・新規 1（`Rotated` story）。
