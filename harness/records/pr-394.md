# PR #394 リサイズハンドルを実要素にして、枠線をまたぐ 8 個にする

- マージ日: 2026-09-02
- 関連 Issue: #371（分離先: #396 / #397）
- 差分規模: 35 ファイル / +1531 -447（20 コミット）

## ゴールと結果

#371: 選択すると右辺と下辺だけ線が太く見える、という症状を直す。

達成した。ただし**ゴールは 3 回広がり、実装は 4 段階を経ている**。

1. 帯（右辺・下辺いっぱいの 8px）→ 四隅の四角 4 個
2. オーナーの「普通ハンドルって角とそれぞれの間の部分じゃない？」→ **8 個**
   （`docs/06-ui.md` を仕様変更。UI 案は Figma に倣った 4 個）
3. オーナーの「ハンドル部分でカーソル変わらなうのと、ハンドルの真ん中に矩形の線が
   来るようにハンドル配置しないっけ？」→ **擬似要素から実要素へ作り替え**
4. オーナーの「４つかどそもそもリサイズにカーソル変わらないし、大きさかえれない」→
   **右下の角で 2 軸同時**

2〜4 はいずれも別 PR にしようとしたところをオーナーが「このPRで直して欲しいんだが？」と
差し戻している。残り 5 個のハンドルは #396、`use-text-edit` の重複は #397 へ分離した。
