- マージ日: 2026-09-13

## ゴールと結果

左ペイン `Layers` に検索欄を付け、`Artboards` の一覧とツリーの両方を名前で絞り込めるようにする
(#498 で決めた案 B)。達成した。

ずれが 1 つある。Issue #423 本文は「**ドメインの変更を伴わない**(絞り込みは表示側の関心事)」と
書いていたが、案 B では「その artboard の配下に一致があるか」が artboard / ノードの性質になるため、
ドメイン側に `Node.hasMatchingName` / `Artboard.hasMatchingName` を足すことになった。着手時に
Issue へ書き残してある。

## うまくいったこと

- **ミューテーションで実測してから残した。** 「絞り込み中は掴めない」「Tokens に欄が出ない」
  「絞り込み中は三角が出ない」「絞った並びは掴めない」「`isSome` の型述語」の 5 つとも、ガード側を

- **UI 案に無いものを自分で決めずに止めた。** 検索欄は UI 案のどの画面にも無く、`harness/case-law/ui.md`
  「対象が UI 案のどの画面にも無いと確かめたら、その時点で止めて確認する」に従って #498 で判断を仰いだ。
  最初に自分で推した案 A(ツリーだけ絞る)はオーナーの質問で覆っており、止めていなければ Figma より
  狭い仕様が入っていた
- **外部の挙動を動かして確かめた。** `<input type="search">` がネイティブの `×` を描き Esc で消える
  ことを Chromium で確認し、計画していた「消すボタンを持たない」の規定を撤回した(既存の `Assets` の
  欄と矛盾するところだった)
- **VRT の差分を 1 件ずつ突き合わせた。** レポートの一覧を実際に引いて、15 件がすべて左ペインを
  含む画面、新規 8 件が今回足したストーリーと 1 件ずつ一致することを確かめてから `visual-approved`
