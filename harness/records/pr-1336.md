# PR #1336 公開 prop の enabledWhen を binding 先ノードの props で判定する

- マージ日: 2026-11-10

## ゴールと結果

ゴールは「インスタンスの公開 prop の欄が出るかどうか(`enabledWhen`)を、binding 先ノードの props(部品内の値 + 途中とインスタンスの上書き + 既定)で判定する」。達成した。Issue の 3 ケース(公開名と binding 先の名前が違う / 条件の prop を公開していない / 別ノードの座標)と入れ子のケースは、main で落ちるテストとして再現してから直した。

計画の検証の段階で、インスタンスの欄の `enabledBy` を「同じ部品にある条件の行の公開名(無ければ none)」にすることを範囲に足した。直すと、ラベルが隠れて字下げされた欄が、ぶら下がる先の行が無いまま出るため(指摘 1)。

GitHub 上の人のレビューは 0 件だった。`get_reviews`・`get_review_comments`・`get_comments` の 3 つとも確認した。コメントは、自分が投稿したテストケース表と bot の投稿(Storybook プレビュー・CI レポート・VRT)だけ。CI は全件緑で、VRT の差分は 0 件だった(209 件 passed)。
