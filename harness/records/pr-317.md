- マージ日: 2026-08-25
- 関連 Issue: #43
- 差分規模: 54 ファイル / +1895 -297

## ゴールと結果

`Artboards` の一覧から artboard を足せる・並べ替えられるようになり、選んだ artboard を
Delete キーで消せるようになる。**達成した。**

ただし**ゴールの範囲がレビュー中に変わった**。当初の並べ替えは行ごとの `↑` / `↓` ボタンで、
PR 提出後に「ボタンで入れ替えるのはダサイ / それならドラッグで移動できた方がいい」という
指示を受け、**この PR の中で全面的にドラッグへ切り替えた**（artboard の一覧だけでなく、同じ
左ペインのツリーも含む）。横断層に `ReorderDrag` / `useReorderDrag` / `DropLine` を新設し、
`↑` / `↓` を押していた 8 ファイルのテストを書き換えている。結果として差分は当初計画の
おおよそ 2 倍になった。

スコープ外へ出したものが 2 つある。キャンバス下部ツールバーの `#` スロット（→ #316）と、
キーボードだけで並べ替える経路（`↑` / `↓` が唯一の入口だったので、寄せた時点で 0 になる。
UI 案にも `docs/06-ui.md` にも無いため発明を避けて別 Issue へ）。
