## ゴールと結果

ゴールは次のとおり。キャンバスで選んでいないノードを押して運ぶと、押した時点(`pointerdown` で掴めたとき)でそのノードが選ばれ、運び終えても・取り消しても選ばれたままになる。名前の変更・Text のインライン編集の最中に押しても、打っていた内容は今と同じく編集していたものへ確定する。`docs/06-ui.md` に追記する。

達成した。Issue の「決めること」1・2 は動作を変える判断だったので、選択肢と推奨を Issue に書いて判断待ちで止め、オーナーの回答「おすすめでいいよ」(推奨 A: 押した時点で選ぶ / a: 取り消しても戻さない)で確定した。複数選択中に一員を押すと 1 つの選択に崩れる後退は #1298 に分離した。

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。コメントは、自分が投稿したテストケース表と bot の投稿(Storybook プレビュー・CI レポート・VRT)だけだった。CI は全件緑で、VRT の差分は 0 件(209 件 passed)。
