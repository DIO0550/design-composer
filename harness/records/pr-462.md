- 発火: 計測対象外(フック不発)

不発への対処として次を手順の側で守った。

- push 前検査を `&&` で連ねず 1 つずつ独立に実行し、それぞれの結果行を確認(7 項目すべて緑)
- `implementation-flow`「検証エージェント実行中に git add / commit / push を挟まない」を手動で守った(`block-git-during-verification-agent.sh` が効かないため)。エージェント完了後の `git status --porcelain` で未ステージの書き換え 0 件も確認
- **`git add -A` を 1 度使ってしまい、`commit` スキルの禁止コマンドに気づいて `git reset` してから 33 ファイルを個別に add し直した**。`no-git-add-all` フックが効いていれば止まっていた操作
