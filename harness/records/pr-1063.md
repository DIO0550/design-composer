## ゴールと結果

ゴールは「開始画面で『開く』と『新規作成』が押せる導線としてひと目で分かり、どちらが何をするか（説明とショートカット）が読める」。達成した。2 枚のカードにし、名前は見出しだけ（`aria-labelledby`）、説明とショートカットは `aria-describedby` で読ませた。

PR オーナーのレビューで、カードを共通コンポーネント `src/components/action-card/` に移した。開始画面の見た目・名前・テストは変えていない。

GitHub 上の人のレビューは 1 件（行コメント）だった。`get_reviews` の 2 件はどちらも本文が無い COMMENTED で、1 件はその行コメント、もう 1 件はこちらの返信のもの。`get_comments` には、自分のテスト表・VRT の確認結果と bot の投稿しか無かった。CI は visual-regression 以外すべて緑。visual-regression は意図した差分（変更 9 件・新規 3 件）で赤のまま。
