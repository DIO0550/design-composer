- マージ日: 2026-09-12

- 差分規模: 22 ファイル / +419 -91

## ゴールと結果

Box に `opacity` を書けるようになり、コンパイル結果に `opacity` が出て、値域（0〜1）を
外れた値はエラー一覧に出る。達成した。

Issue が「判断が要る点」として挙げていた「生リテラルにするかトークンにするか」は生リテラル
側へ倒したが、その帰結として `docs/02-data-model.md` の基本原則（見た目に関わる値は必ず
トークン参照 / 生リテラルは構造値と内容に限る）へ「トークン種別を持たない見た目の値」の枠を
足す仕様変更を含むことになった。この範囲は Issue には書かれておらず、計画の検証で初めて
出た（下記 指摘 1・2）。
