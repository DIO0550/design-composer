- マージ日: 2026-09-19

## ゴールと結果

当初のゴールは Issue #624 の 3 点(`--ratchet` / 綴りごとの窓 / `--unused` の廃止)を
main へ移すことだった。**作業中に別セッションの #625 が同じ 3 点を先に main へマージし、
#624 はクローズされた。** 実装は完了していたが重複になったため、衝突箇所をすべて
main の版へ寄せ、main に無い「集計の判定表(`count-cases.sh`)」とその配線だけを残す形へ
再スコープし、#628 を立て直して閉じた。

こちらの実装と #625 の実装は、記録 120 本に対する出力(13 行の 再発 / 内部 / 通算 / 以降)が
完全に一致していた。数え方そのものに食い違いは無かった。
