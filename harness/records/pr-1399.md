## ゴールと結果

ゴールは次のとおり。中身の変わらない編集（値を変えずに欄を離れた確定など）では進む先（redo）を捨てず、undo したあと欄を Tab で通るだけでも redo できる。中身の変わらない 1 件目に続き（`amend`）が届いて中身が変わったら、そのとき進む先を捨てる。`docs/06-ui.md` の undo / redo の行を揃える。

達成した。Issue は「残すかを決める」から始まる形だったので、フェーズ 1 で「残す」を選び、理由（#1379 で undo に数えないことにしたのと対称）を Issue に書いた。判断待ちで止めた回は無い。判定は `EditHistory` の非公開関数 `futureAfter`（新しい現在地を今の現在地と比べる）に置き、`record` / `amend` から使う。`redo` の入口でも `withoutUnchangedLast` を通した（見える挙動は変えず、型 doc の不変条件を保つため）。

GitHub 上の人のレビューは 0 件だった。`get_reviews` / `get_review_comments` / `get_comments` の 3 つとも確認した。`get_reviews` の 1 件は Copilot の概要（open issue 0 件）。`get_comments` の DIO0550 の 1 件は、自分が貼ったテスト表。残りは github-actions の Storybook プレビュー・CI レポート・VRT。CI は全件緑で、VRT の差分は 0 件（210 件 passed）。
