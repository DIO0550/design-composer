# PR #542 🐛 [Bug fix]: #540 プロパティパネルの入力を、欄を離れるまでで 1 つの undo にまとめる

- マージ日: 2026-09-15
- 関連 Issue: #540
- 差分規模: 23 ファイル / +478 -135

## ゴールと結果

ゴールは「プロパティパネルの数値欄・文言欄で打ち替えたあと**欄を離れてから** Ctrl+Z を 1 回押すと、その欄で打ち始める前の値へ戻る（打鍵ごとには戻らない）。選択式の欄は今までどおり 1 回の選び直しが undo 1 件」。達成した。

**ゴールの文は計画の検証で 1 度書き直している。** 当初は「打ち替えたあと Ctrl+Z を 1 回」だったが、入力欄にフォーカスがある間はどのキーボード割り当ても通らない（`docs/06-ui.md:166`）ため、そのままではテストも実機も成立しなかった（指摘 1）。

まとまりの境界は **A（focus / blur）** を採り、B（時間で区切る）・C（`onChange` をやめて確定で 1 回だけ送る）は却下した。C は「打っている最中のキャンバスの追従をやめる」という別の判断になるので、必要になった時点で別 Issue とする判断を Issue #540 に残した。

`hasEdited`（`prop-field`）と `hasResized`（`use-node-resize`）の共通化は据え置き、続きとして **#550** を立てた。
