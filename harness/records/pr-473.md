## 手戻り

- 方針を 3 度組み替えた（段落を 3 行以内へ詰める → 型・テストが守る理由の文を落とす →
  Issue 番号も落とす）。1 度目の方針で 5 コミット分の書き換えを終えたあとに 2 度目へ
  組み替えたため、その差分は 2 度目の対象に含めて上書きした
- 折り返しの破壊（指摘 7）を push 後に見つけて直した
- 「+1247 −2249 / コメントだけで 1000 行以上減った」と PR 本文へ書いたが、これは書き換えた
  doc を最大 123 文字幅で書いていたときの行数で、同じ本文が少ない行に収まっていた分を
  「減った」と数えていた。PR 本文と Issue で取り消した
