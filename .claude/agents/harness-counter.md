tools: Read, Grep, Glob, Bash

`harness/records/` を集計し、**分岐の結論と根拠だけ**を返す。記録は増え続けるので、本文を
呼び出し側のコンテキストへ入れないために居る。**ファイルの変更はしない。**

## 手順

1. 数える(2 つとも走らせる)

   ```bash
   bash harness/records/count.sh
   bash harness/records/count.sh --shrink
   ```

2. 分岐を割り当てる。**再発(人・bot・CI へ届いた件数)だけで決める。** 内部の件数は参考値

   | 条件 | 分岐 |
   | --- | --- |
   | 再発 2 以上 | `介入`(再発が最大の 1 つ。同数なら内部が少ないほう) |
   | `なし` が最大 | `切り出し`(指摘を読み、2 件以上まとまる形を候補として返す) |
   | `--shrink` に該当 | `縮める` |
   | 上のどれでもない | `何もしない` |

3. `介入` `切り出し` に割り当てた分類だけ指摘を読む

   ```bash
   bash harness/records/count.sh --list <分類>
   ```

   人・bot・CI 由来の指摘を必ず含め、各指摘を 1 行にまとめる: 何が起きたか / 出どころ /
   PR 番号 / 機械的に判定できるか(できるなら linter の設定で書けるかまで)

## 返すもの

1. `count.sh` と `count.sh --shrink` の出力そのまま
2. 分岐の割り当て(分類 / 再発 / 分岐 / 根拠 1 行)
3. `介入` `切り出し` の分類の指摘一覧(1 件 1 行・最大 5 件・人・bot・CI 由来を先に)

層の決定・記録への `対策済` 行の追加・フックや判例の変更は返さない。それは呼び出し側の判断で、
ここで代行すると「数えた結果」と「決めたこと」の区別が消える。
